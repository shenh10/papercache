Group Sequence Policy Optimization

文章标题：组序列策略优化 (Group Sequence Policy Optimization)
作者/机构：Chujie Zheng∗, Shixuan Liu, Mingze Li, Xiong-Hui Chen, Bowen Yu∗, Chang Gao, Kai Dang, Yuqiong Liu, Rui Men, An Yang, Jingren Zhou, Junyang Lin (Qwen Team, Alibaba Inc.)

速读

一句话结论 本文针对大语言模型强化学习中 GRPO 算法存在的严重崩溃问题，提出了组序列策略优化（GSPO）算法，通过将重要性采样和裁剪机制从 token 级别提升到序列级别，实现了更稳定高效的训练，并为 Qwen3 模型带来了显著的性能提升。

要解决什么问题 现有的强化学习算法（如 GRPO）在训练大语言模型时，常面临严重的稳定性问题，极易导致灾难性且不可逆的模型崩溃。这个卡点的核心机制在于 GRPO 对重要性采样权重的误用。为了最大化硬件利用率，强化学习通常采用大批量采样并切分为多个小批量进行梯度更新，这不可避免地引入了离策略学习设置。在处理新旧策略分布不匹配时，GRPO 错误地在单个 token 级别应用重要性采样权重。由于奖励是针对整个序列发放的，在 token 级别进行离策略校正不仅目标错位，还会引入极高方差的训练噪声。这种噪声会随着响应长度的增加而不断累积，并被裁剪机制进一步放大，最终摧毁模型。此外，在训练混合专家（MoE）模型时，由于梯度更新前后激活的专家会发生显著变化，token 级别的重要性比率会剧烈波动并彻底失效，以往只能依赖引入额外内存和通信开销的复杂策略来勉强维持稳定。

怎么做的 方法的核心思路是将优化目标的粒度与奖励发放的粒度严格对齐，彻底放弃 token 级别的重要性权重，转而在完整的序列级别计算重要性比率并执行裁剪与优化。为了绕开 token 级噪声累积的卡点，GSPO 首先采用基于组的优势估计，计算同一查询下多个响应的相对优势：$$A_i = \frac{r_i - \text{mean}(r)}{\text{std}(r)}$$接着，GSPO 摒弃了逐 token 计算的做法，基于完整的序列似然来定义重要性比率，并引入长度归一化以控制数值范围、降低方差，防止少数 token 的似然变化导致整体比率剧烈波动：$$s_i(\theta) = \exp \left( \frac{1}{|y_i|} \sum_{t=1}^{|y_i|} \log \frac{\pi_{\theta}(y_{i,t}|x, y_{i,<t})}{\pi_{\theta_{old}}(y_{i,t}|x, y_{i,<t})} \right)$$最终的序列级优化目标函数通过对整个响应应用裁剪机制，将过于偏离旧策略的样本排除在梯度估计之外：$$J_{GSPO}(\theta) = \mathbb{E}_{x \sim D, y \sim \pi_{\theta_{old}}} \left[ \frac{1}{G} \sum_{i=1}^G \min \left( s_i(\theta) A_i, \text{clip}(s_i(\theta), 1-\epsilon, 1+\epsilon) A_i \right) \right]$$这一设计的关键在于，在计算对数似然梯度时，GSPO 对同一个响应中的所有 token 赋予了完全相同的权重。相比之下，GRPO 会根据每个 token 自身的重要性权重对其梯度进行缩放，导致权重在极小值到极大值之间剧烈震荡。GSPO 的等权设计彻底消除了这种不稳定性。此外，针对多轮强化学习等场景，作者设计了 GSPO-token 变体，允许在保持序列级重要性比率稳定的前提下引入 token 级别的优势定制。由于 GSPO 只关注序列似然，它对训练和推理引擎间的精度差异容忍度极高，系统可直接使用推理引擎返回的似然进行优化，省去了用训练引擎重新计算的繁琐步骤，大幅简化了基础设施。

效果如何 实验基于从 Qwen3-30B-A3B-Base 微调的冷启动模型进行，在 AIME’24、LiveCodeBench 及 CodeForces 等基准上测试了生成能力。对比的核心基线是 GRPO 算法，它代表了当前主流的基于 token 级别相对优势的强化学习路线。在相同的训练计算量和查询消耗下，GSPO 展现出了显著优于 GRPO 的训练效率和最终性能，且训练全程保持稳定。实验中出现了一个反直觉的量化结果：GSPO 和 GRPO 在被裁剪 token 的比例上存在 2 个数量级的巨大差异。尽管 GSPO 触发裁剪机制的频率远高于 GRPO，导致实际参与训练的 token 数量更少，但其训练效率依然更高。这直接证明了 GRPO 的 token 级梯度估计存在固有的高噪声，样本利用率极其低下。在混合专家模型的设置下，GSPO 的优势更为明显：基线 GRPO 必须绑定 Routing Replay 策略（即强制重放旧策略的路由模式）才能勉强收敛，而 GSPO 完全不需要这种复杂的变通方法就能稳定训练，从根本上解决了专家激活波动带来的崩溃问题。作者也提到，由于重要性比率定义的改变，GSPO 的裁剪范围超参（如 3e-4 到 4e-4）与 GRPO（如 0.2 到 0.27）在数量级上完全不同，实际应用中需重新调整。

A1 主要贡献

本文针对现有强化学习（RL）算法在训练大型语言模型时（特别是GRPO算法）存在的严重稳定性问题，提出了组序列策略优化（Group Sequence Policy Optimization, GSPO）算法。

  • 核心问题：当前最先进的RL算法如GRPO【7，Shao et al., Deepseekmath: Pushing the limits of mathematical reasoning in open language models, 2024】在训练大型语言模型时表现出严重的稳定性问题，常导致灾难性且不可逆的模型崩溃。这种不稳定性阻碍了通过持续的RL训练来推动语言模型能力边界的努力。本文识别出GRPO的不稳定根源在于其算法设计中对重要性采样权重的根本性误用和失效，这引入了高方差的训练噪声，该噪声会随着响应长度的增加而累积，并被裁剪机制放大，最终导致模型崩溃。

  • 研究目标：提出一种新的、稳定的、高效的、高性能的RL算法，以解决GRPO的核心局限性，从而支持大规模语言模型的RL训练。

  • 核心创新点（GSPO算法）：

    1. 基于序列似然的重要性比率：GSPO的关键创新在于其理论上合理的、基于序列似然的重要性比率定义【8，Zheng et al., CLICK: Controllable Text Generation with Sequence Likelihood Contrastive Learning, 2023, ACL】，这与重要性采样的基本原则相符，纠正了GRPO在token级别应用重要性采样的错误。
    2. 序列级优化：GSPO在序列级别进行裁剪、奖励计算和优化。它将归一化奖励计算为对同一查询的多个响应的优势（advantage），确保了序列级奖励与序列级优化之间的一致性。

  • 主要成果：

    • 性能优越：实证评估表明，GSPO在训练稳定性、效率和性能上均显著优于GRPO。
    • 稳定MoE训练：GSPO从本质上解决了大型混合专家（MoE）模型RL训练中的稳定性挑战，不再需要复杂的稳定策略（如Routing Replay）。
    • 简化基础设施：GSPO展示了简化RL基础设施的潜力。
    • 实际应用：这些优点为最新的Qwen3模型带来了卓越的性能提升。

离策略学习设置与GRPO的问题。模型规模、稀疏性（例如在混合专家模型中）和响应长度的增长，要求在RL期间使用大的rollout批量大小以最大化硬件利用率。为了提高样本效率，标准做法是将一个大的rollout数据批次划分为多个小批次进行梯度更新。此过程不可避免地引入了离策略学习设置，其中响应 $y$ 是从旧策略 $\pi_{\theta_{old}}$ 而不是正在优化的当前策略 $\pi_{\theta}$ 中采样的。这也解释了PPO和GRPO中裁剪机制的必要性，该机制防止过于“离策略”的样本参与梯度估计。尽管裁剪等机制旨在管理这种离策略差异，但我们发现GRPO中存在一个更根本的问题：其目标是病态的（ill-posed）。当在长响应任务上训练大模型时，这个问题变得尤为严重，会导致灾难性的模型崩溃。

A5 实验结果

5.1 经验性结果：GSPO vs. GRPO

  • 实验内容：对比GSPO与GRPO在Qwen3-30B-A3B-Base模型上的训练过程，评估训练稳定性、效率和最终性能。
  • 实验结果：
    • 稳定性：GSPO的训练过程全程稳定。通过增加训练计算量、定期更新查询集和延长生成长度，GSPO能够持续提升性能。
    • 效率：GSPO表现出比GRPO更高的训练效率。在相同的训练计算量和消耗的查询下，GSPO获得了更好的训练准确率和基准性能。
  • 分析结论：GSPO在训练大型语言模型方面显著优于GRPO，并已成功应用于最新的Qwen3模型的RL训练中，证明了其在释放RL扩展潜力方面的有效性。

  • 图表引用：图1展示了GSPO的训练效率明显高于GRPO。

5.2 关于裁剪比例的奇特观察

  • 实验内容：比较GSPO和GRPO在RL训练过程中的平均被裁剪token的比例。
  • 实验结果：GSPO和GRPO之间被裁剪token的比例存在两个数量级的差异。尽管GSPO裁剪了显著更多的token（从而用于训练的token更少），但其训练效率仍然高于GRPO。
  • 分析结论：这一反直觉的发现——裁剪更大部分的token反而带来更高的训练效率——进一步表明GRPO的token级梯度估计存在固有的噪声且样本利用效率低下。相比之下，GSPO的序列级方法提供了更可靠和有效的学习信号。

5.3 GSPO对MoE训练的益处

  • 实验内容：分析MoE模型在RL训练中的稳定性挑战，并说明GSPO如何解决这些问题。
  • 背景：与密集模型相比，MoE模型的稀疏激活特性带来了独特的稳定性挑战。在使用GRPO算法时，MoE模型的“专家激活波动性”会阻止RL训练正常收敛。具体来说，梯度更新后，为同一响应激活的专家会发生显著变化（例如，在48层的Qwen3-30B-A3B-Base模型上约有10%的专家不同），这导致token级重要性比率剧烈波动并失效，阻碍训练。
  • GRPO的解决方案：之前采用“Routing Replay”策略，即缓存旧策略 $\pi_{\theta_{old}}$ 激活的专家，并在计算重要性比率时在 $\pi_{\theta}$ 中“重放”这些路由模式。这能恢复token级重要性比率的稳定性，但会带来额外的内存和通信开销，并可能限制MoE模型的实际容量。
  • GSPO的优势：GSPO无需依赖Routing Replay即可稳定收敛。其关键在于GSPO只关注序列似然 ($\pi_{\theta}(y_i|x)$)，对单个token似然 ($\pi_{\theta}(y_{i,t}|x, y_{i,
  • 分析结论：GSPO从根本上解决了MoE模型中的专家激活波动问题，无需像Routing Replay这样的复杂变通方法。这不仅简化和稳定了训练过程，还允许模型在没有被人为限制的情况下充分利用其全部能力。

A7 补充细节

5.4 GSPO对RL基础设施的益处

GSPO对RL基础设施的益处。考虑到训练引擎（如Megatron）和推理引擎（如SGLang和vLLM）之间的精度差异，在实践中，我们通常使用训练引擎来重新计算旧策略 $\pi_{\theta_{old}}$ 下采样响应的似然。

简化计算流程的潜力。然而，GSPO仅使用序列级而非token级的似然进行优化，直观上，前者对精度差异的容忍度要高得多。因此，GSPO使得直接使用推理引擎返回的似然进行优化成为可能，从而避免了使用训练引擎进行重新计算的需要。这在部分rollout、多轮RL以及训练-推理分离的框架中尤其有益。

A5 结论

本文提出了组序列策略优化（GSPO），一种用于训练大型语言模型的全新强化学习算法。GSPO遵循重要性采样的基本原则，基于序列似然定义重要性比率，并执行序列级的裁剪、奖励和优化。与GRPO相比，GSPO在训练稳定性、效率和性能方面表现出显著的优越性，并且对于大规模MoE模型的RL训练尤其有效，为最新的Qwen3模型的卓越改进奠定了基础。以GSPO作为可扩展的算法基石，团队将继续扩展RL的应用，并期待由此带来的智能领域的根本性进步。
