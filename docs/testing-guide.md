# 用户管理系统测试指南

## 测试前准备

1. **确保本地配置正确**
   ```bash
   # 运行配置同步脚本
   ./scripts/load-env-to-config.sh
   
   # 启动本地开发服务器
   bundle exec jekyll serve --config _config.yml,_config_local.yml
   ```

2. **检查浏览器控制台**
   - 打开开发者工具（F12）
   - 查看 Console 标签，确认没有 Supabase 初始化错误

## 常见问题排查

### 问题1：Supabase客户端未初始化
**症状**：控制台显示 "Supabase客户端未初始化"
**解决**：
- 检查 `_config_local.yml` 中的 Supabase 配置是否正确
- 检查 `.env.local` 文件是否存在且包含正确的值
- 运行 `./scripts/load-env-to-config.sh` 重新同步

### 问题2：GitHub OAuth登录失败
**症状**：点击GitHub登录后重定向失败
**解决**：
- 检查Supabase Dashboard中的GitHub Provider配置
- 检查回调URL是否正确：`https://<project-ref>.supabase.co/auth/v1/callback`
- 检查GitHub OAuth App中的回调URL配置

### 问题3：收藏功能不工作
**症状**：点击收藏按钮无反应
**解决**：
- 检查浏览器控制台是否有错误
- 检查是否已登录
- 检查Supabase数据库表 `favorites` 是否创建
- 检查RLS策略是否正确配置

### 问题4：用户菜单不显示
**症状**：登录后看不到用户头像
**解决**：
- 检查 `assets/js/user-menu.js` 是否加载
- 检查认证状态是否正确更新
- 检查浏览器控制台是否有JavaScript错误
